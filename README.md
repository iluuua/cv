## Что я делаю в проде

Веду LLM-контур [ReachFlow](https://reachflow.tech) — B2B SaaS, где ИИ-ассистент ведёт продающие
переписки в Telegram. Это не «прикрутил ChatGPT к боту», а конвейер, который должен отвечать
предсказуемо, дёшево и не ломаться, когда провайдер отдаёт 500.

**Конвейер диалога** — 8 вызовов модели на одно входящее сообщение: гейт батча, классификатор
состояния лида (16 типов событий, каждое с якорем на конкретное сообщение и confidence),
извлечение и взвешивание фактов (18 типизированных ключей, версионированная политика памяти
с порогами хранения), стратег → гуманизатор → ревьюер, планировщик отправки.

**Снизил стоимость хода.** Слил пять классификаторных вызовов в два — одна модель отдаёт несколько
секций одним объектом. 10 вызовов на сообщение стало 8, входных символов на стадии классификации
на 14–43% меньше. При этом каждая секция сохранила собственный режим отказа: невалидная
помечается `unanswered` и ни на что не влияет, вместо того чтобы уронить весь ход.

**Strict structured output.** Реестр из 25 LLM-задач и 22 JSON-схем на pydantic с `extra="forbid"`,
нормализация схем под strict-режим провайдеров, валидация ответа на своей стороне — нарушение
схемы считается retryable-ошибкой, а не тихо проглатывается. Исполнитель с ретраями, каскадом
фолбэков между вендорами и трейсом каждой попытки: модель, latency, retry, стоимость.

**Роутер моделей.** Доменный код называет роль работы — квалификация кандидата, компиляция
критериев аудитории, живой диалог, тяжёлое рассуждение, — а роутер разворачивает её в цепочку
`primary → fallback`. Id моделей живут только в переменных окружения: перенастройка флота
не требует правки кода.

**ИИ-агент с инструментами.** Реестр `ToolSpec` — единственный источник правды сразу для четырёх
потребителей: блока инструментов в системном промпте, гейта привилегий по уровню риска, границы
доверия (какие поля оборачиваются как недоверенные) и MCP-эндпоинта, где схема аргументов
становится `inputSchema`.

**Разобрал провал семантического гейта.** Косинусная близость на эмбеддингах
(`text-embedding-3-small`, 1536, pgvector с HNSW) отбраковывала 55 кандидатов из 63 — оказалось,
она мерила формат и длину текста, а не релевантность. Перевёл гейт из блокирующего
в наблюдательный, решение оставил за LLM-квалификацией с машиночитаемой причиной отказа.
