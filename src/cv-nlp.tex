\begin{itemize}
  \item Реализовал \textbf{Lift--Splat--Shoot} на PyTorch с нуля: общий для камер ResNet-50 с

  \item Основной прирост дала покадровая калибровка вместо фиксированной; лосс --- BCE с
        \texttt{pos\_weight} по балансу классов плюс дифференцируемый surrogate mIoU. Итог ---
        \textbf{IoU 0.5606} на скрытом тесте при 0.564 у команды-победителя.
        Код: \href{https://github.com/iluuua/aidao-2025-bev-occupancy}{github.com/iluuua/aidao-2025-bev-occupancy}
\end{itemize}
