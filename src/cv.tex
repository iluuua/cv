\section{Опыт работы}
\role{ReachFlow\normalfont\enspace\textit{Основатель и разработчик}\enspace\href{https://reachflow.tech}{\underline{reachflow.tech}}}{с января 2026}
Сервис для отделов продаж, которые ведут переписку в Telegram.
\begin{itemize}
  \item Сократил число вызовов LLM для классификации сообщения с пяти до двух, убрав повторную передачу истории. В типовом тестовом диалоге объём входного текста уменьшился на 38\%, в коротком на 14\%, в длинном на 43\%.
  \item Сравнил пять моделей для проверки черновиков на восьми примерах, включая пять с намеренными ошибками. Упростил JSON-схему и увеличил лимит токенов. Две модели выдали корректный JSON во всех восьми случаях, до изменений у каждой было пять из восьми.
  \item Подключил внешних ассистентов к ReachFlow через MCP с OAuth~2.1. Проверил чтение данных в четырёх клиентах (ChatGPT, Codex, Gemini и Grok). В чат ReachFlow встроил формы выбора продукта и сегмента клиентов с проверкой на сервере.
  \item Объединил 20 быстрых тестов схем данных и контрактов API в одну команду для Codex. С Claude добавил сверку чисел в ответах агента с перепиской и базой знаний. Если после повторной генерации число остаётся неподтверждённым, черновик получает менеджер.
\end{itemize}
