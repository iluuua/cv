\section{Опыт работы}
\role{ReachFlow\normalfont\enspace\textit{Основатель и разработчик}\enspace\href{https://reachflow.tech}{\underline{reachflow.tech}}}{с января 2026}
Сервис для отделов продаж, которые ведут переписку в Telegram.
\begin{itemize}
  \item Разработал диалогового LLM-агента с планированием и проверкой ответов по истории переписки. Сократил число вызовов классификатора с пяти до двух и объём входного текста на 38\% в типовом тестовом диалоге.
  \item Построил поиск клиентов в Telegram на основе обхода графа сообществ в ширину (BFS) и LLM-оценки сообщений. Подходящие контакты и сделки система добавляет в CRM без дублей.
  \item Сравнил четыре LLM на 35 реальных черновиках для каждой. Измерял стоимость вызова и проверял, сохраняет ли модель утверждённый текст при разбиении на сообщения.
  \item Разработал сервис вызова LLM через OpenRouter. Он выбирает модель по типу задачи, переключается на резервную при сбое, проверяет ответы через Pydantic и учитывает стоимость каждого вызова.
\end{itemize}
